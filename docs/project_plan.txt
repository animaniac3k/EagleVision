1. OVERVIEW & DESIGN PHILOSOPHY
-------------------------------
EagleVision is an installable, offline-capable Progressive Web App (PWA) built
for the Lenovo IdeaPad Duet 3 (10.95" 2000x1200 16:10 touch display, ChromeOS),
Android tablets, and Windows/Linux/macOS laptops. It connects to external USB
cameras (UVC webcams, microscopes, inspection scopes, capture cards) and provides:

  - 100% Full-Screen Camera Viewport with minimal UI footprint
  - Touch-first controls (52px hit targets, 16px-18px high-contrast typography)
  - Top-Left Unified Toolbar: Settings Toggle, PiP Zoom Window Toggle (POI icon),
    Overlay Guide On/Off Toggle, Micro-Change Heatmap Toggle, Telemetry HUD Toggle,
    and the Whole-Image Zoom Stepper (- / 1.0x / + / 1:1) at the end of the strip
  - Dynamic Radar/Instrument Appearance Engine:
      * 6 tactical color swatches + live 2D color picker (HSL CSS token engine)
      * Global Interface Opacity slider (15%-100%, `--ui-opacity`) that fades all
        floating UI panels, strips, and windows in and out together
  - Movable, Corner-Resizable Digital Zoom Window (PiP Magnifier) with a
    decoupled, hideable ROI Target Crosshair
  - Simplified Superimposed Overlay Guide:
      * Unobstructed Open-Center Crosshair (64x64px center gap with inner bracket
        ticks and no outer circle so the point of interest is never obscured)
      * Custom local image loader (`LOAD IMG` for PNG/SVG/WebP guides)
  - Localized Micro-Change Heatmap Engine:
      * Highlights subtle, localized changes in high-contrast thermal/radar colors
      * Global Motion Gate (>18% whole-frame change) rejects camera shake/panning
      * Adjustable Sensitivity (10%-95%) and Display Duration (0.5s-10.0s)
  - Native-Resolution Configurable In-Memory Frame Ring Buffer:
      * Adjustable Duration (5s-60s) and Frame Rate (5-30 FPS) in RAM
      * Live Memory Availability Meter (USED MB vs. ESTIMATED MB vs. FREE RAM Budget)
  - One-Tap Instant Replay with Auto-Save to IndexedDB Archive
  - Fullscreen Stored Video Player (Screen 2) with floating GUI overlay, collapsible
    Clips drawer, 0.5x slow-motion, STEP +1 frame advance, and native-resolution
    .webm file export to disk
  - 5-Button Bluetooth Scrolling Ring Remote Controller (`ringController.js`) with
    mode cycling (`AIM ROI` -> `ZOOM` -> `TOOLS` + automatic `PLAYER` transport),
    double-click Instant Replay, and live 5-button calibration in Settings

3. HOW KEY SUBSYSTEMS WORK & CONNECT
------------------------------------

3.1 Central Reactive State (js/state.js)
  - Holds the single source of truth (`appState`) for main/PiP zoom levels, ROI
    target coordinates (`roiX`, `roiY`), overlay guide state, image adjustments,
    heatmap sensitivity & display duration (`heatmapDuration`), memory ring buffer
    duration/FPS (`bufferMaxSeconds`, `bufferTargetFps`), global interface opacity
    (`uiOpacity`), theme color (`themeColor`), and custom Bluetooth ring bindings.
  - Modules call `updateState(patch)` to mutate state and `subscribeState(fn)`
    to reactively update DOM elements or rendering parameters.

3.2 USB Camera & Pre-Rendered Test Signal (js/camera/streamManager.js)
  - Queries `navigator.mediaDevices.enumerateDevices()` for USB/UVC video inputs
    and listens to `devicechange` for plug-and-play detection.
  - Requests 1920x1080 @ 60fps via `getUserMedia` and feeds `<video id="cameraVideoEl">`.
  - If no camera is connected (or "BUILT-IN TEST SIGNAL" is chosen), pre-renders
    a static 1080p inspection board onto an offscreen bitmap and animates a radar
    scanline and timecode at 30fps with near-zero CPU overhead.

3.3 60fps Dual-Canvas Compositor & Localized Micro-Change Heatmap (js/renderer/compositor.js)
  - Runs a `requestAnimationFrame` loop that reads `<video id="cameraVideoEl">`
    and draws aspect-correct, pan/zoom-cropped frames onto `#mainCanvas`.
  - Simultaneously renders the magnified region centered on `(roiX, roiY)` onto
    `#pipCanvas`, scaled relative to the main canvas pixel ratio (`(cropW * (pw / cw)) / pipZoom`)
    so `3.0x` in the Zoom Window is physically 3.0x larger on screen.
  - Localized Micro-Change Heatmap:
      * Samples a fast 160x90 luminance grid each frame.
      * Global Motion Gate: if >18% of cells change simultaneously (camera movement),
        immediately re-anchors `refLuma` and suppresses global heatmap spikes.
      * Localized changes accumulate thermal intensity and decay exponentially
        using `Math.exp((-2.545 * dtSec) / heatmapDuration)` so markings persist
        on screen for the exact user-selected Display Duration (0.5s to 10.0s).

3.4 Decoupled ROI Crosshair & Corner-Resizable Zoom Window (js/renderer/zoomWindow.js)
  - `#zoomTargetCrosshair` can be dragged by touch or nudged via the 5-button
    Bluetooth ring to update `(roiX, roiY)`, and toggled via the POI reticle button
    inside the Zoom Window header.
  - `#pipZoomWindow` can be dragged or resized from its bottom-left (`#pipResizeSW`)
    or bottom-right (`#pipResizeSE`) corner handle, and is clamped within viewport
    bounds on window resize.

3.5 Open-Center Crosshair & Custom Image Overlay (js/renderer/overlayManager.js)
  - Toggled from either the Top-Left bar (`#btnToggleOverlayTop`) or Settings (`#btnToggleOverlay`).
  - Renders a pure Open-Center Crosshair (horizontal and vertical arms with a 64x64px
    center gap and 4 inner bracket ticks, with no circular ring) or a user-loaded
    image (`LOAD IMG`), with adjustable Opacity and Scale.

3.6 Native-Resolution Configurable In-Memory Ring Buffer (js/recorder/memoryRingBuffer.js)
  - Captures frames at the camera's exact native resolution (`videoWidth x videoHeight`)
    at `bufferTargetFps` (5-30 FPS) for `bufferMaxSeconds` (5s-60s).
  - Stores compressed JPEG `ArrayBuffer`s in RAM and exposes a live memory budget
    meter (`getAvailableMemoryBudgetMB()`, `getEstimatedBufferMB()`) in Settings.

3.7 Auto-Saving Instant Replay & Fullscreen Video Player (instantReplay.js, videoBrowser.js)
  - Pressing `REPLAY` (or double-pressing the Bluetooth Ring Center button) snapshots
    the RAM ring buffer, plays it at native resolution using lightweight `Blob`
    ObjectURLs and a single `HTMLImageElement` decoder, and automatically saves
    the clip into IndexedDB (`EagleVisionVideoDB`).
  - Screen 2 (`#screenGallery`) renders saved clips at 100% fullscreen with a
    floating GUI overlay (collapsible left `CLIPS` drawer + bottom transport bar
    with `PLAY/PAUSE`, `0.5x` slow-mo, `STEP +1`, scrubber, and native-resolution
    `.webm` export).

3.8 5-Button Bluetooth Scrolling Ring Remote (js/ui/ringController.js)
  - Listens for Keyboard (`Arrow*`, `Page*`, `Enter`, `Space`), Consumer Media
    (`AudioVolume*`, `MediaTrack*`, `MediaPlayPause`), and `Wheel` events.
  - Single-press `CENTER` cycles Live modes (`AIM ROI` -> `ZOOM` -> `TOOLS`);
    double-press `CENTER` triggers Instant Replay anywhere.
  - Includes a 5-button D-pad calibration card (`BT Ring Remote`) in Settings.


4. PORTABLE USAGE GUIDE (USB STICK / LAPTOP / CHROMEBOOK)
---------------------------------------------------------
Option A: Running Directly from a USB Stick on Any Laptop (Windows / Mac / Linux)
  1. Copy the `/EagleVision` folder onto your USB drive.
  2. On Windows: Double-click `start_eaglevision.bat` inside the folder.
  3. On macOS / Linux terminal: Run `python3 -m http.server 8080` and open
     `http://localhost:8080` in Chrome, Edge, or Brave.

Option B: Installing as a 100% Offline App on Lenovo Duet 3 / Laptop
  1. Open the app URL in Chrome and click the "Install EagleVision" icon in the
     address bar.
  2. Once installed, launch EagleVision from the app shelf anytime 100% offline.
