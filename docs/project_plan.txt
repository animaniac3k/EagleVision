1. OVERVIEW & DESIGN PHILOSOPHY
-------------------------------
EagleVision is an installable, offline-capable Progressive Web App (PWA) built
for the Lenovo IdeaPad Duet 3 (10.95" 2000x1200 16:10 touch display, ChromeOS),
Android tablets, and Windows/Linux/macOS laptops. It connects to external USB
cameras (UVC webcams, microscopes, inspection scopes, capture cards) and provides:

  - 100% Full-Screen Camera Viewport with minimal UI footprint
  - Touch-first controls (52px hit targets, 16px-18px high-contrast typography)
  - Declutter Mode: Hide all interface chrome with one tap; single restore icon
  - Top-Left Unified Toolbar: Settings Screen Shortcut, PiP Zoom Window Toggle,
    Overlay Reticle Toggle, Micro-Change Heatmap Toggle, Telemetry HUD Toggle,
    and Whole-Image Zoom Stepper (- / 1.0x / + / 1:1)
  - Dedicated Fullscreen Settings Screen (Screen 3):
      * Clean multi-column tactical grid for camera source, memory buffer,
        reticle overlay, heatmap & voice callouts, PS4 gamepad, image filters,
        theme color & global opacity, and Bluetooth ring calibration
  - Dedicated Fullscreen Reticle Customizer & Click Calibration (Screen 4):
      * Live interactive SVG graduated reticle with configurable clicks/indents per arm,
        click pixel spacing, unobstructed center gap for POI, center brackets, major ticks,
        number labels, concentric distance rings, and stroke weight
      * Interactive audition stage: click anywhere on the reticle stage to simulate detection
        and audition female robotic voice announcements
  - Female Voice Detection Announcements (Text-to-Speech):
      * Zero-dependency local Web Speech API synthesis
      * Speaks angle (1 to 12 o'clock) and distance in graduated reticle clicks:
        e.g., "Detection! 11 o'clock, 3 clicks"
      * Dynamically adapts to custom reticle spacing and user overlay zoom scale
      * Configurable voice pitch (female tone) and speech speed
  - PS4 / Bluetooth Gamepad Support (HTML5 Gamepad API):
      * Silent background controller integration for Sony DualShock 4 and standard gamepads
      * Left Analog Stick: Smooth accelerated ROI crosshair aiming
      * Right Analog Stick: Smooth camera pan when zoomed in (>1.0x)
      * L1 / R1: Zoom In / Out; L2 / R2: Step -1 / +1 Frame
      * L3 / R3: Recenter ROI / Reset 1:1 Zoom
      * D-Pad: Zoom Window magnification & Main Zoom / Step
      * Cross (X): Play/Pause / Mode; Circle (O): Return to Live Feed
      * Square: Reticle Toggle; Triangle: Heatmap Toggle
      * Options: 20s Instant Replay (Auto-Save); Share: Settings Screen
  - Localized Micro-Change Heatmap Engine:
      * High-contrast thermal markings for subtle motion; global motion gate rejects camera shake
      * Configurable sensitivity and display duration (custom seconds up to infinity ∞)
  - Native-Resolution In-Memory Video Buffer (5s-60s @ 5-30 FPS) with live RAM meter
  - One-Tap Instant Replay with Auto-Save to IndexedDB Archive and Step -1 / +1 frame buttons
  - Fullscreen Stored Video Player (Screen 2) with floating GUI overlay, collapsible
    Clips drawer, 0.5x slow-motion, dual STEP -1 / STEP +1 frame buttons, and native-res .webm export

3. HOW KEY SUBSYSTEMS WORK & CONNECT
------------------------------------

3.1 Central Reactive State (js/state.js)
  - Holds the single source of truth (`appState`) for all screens (`currentScreen`: 'live' | 'gallery' | 'settings' | 'reticle'),
    zoom levels, ROI target `(roiX, roiY)`, overlay state, reticle configuration (`reticleConfig`),
    heatmap sensitivity, duration (`heatmapDuration`), speech announcements (`heatmapSpeechEnabled`),
    voice settings (`voicePitch`, `voiceRate`), gamepad telemetry, and ring bindings.
  - Subscribed modules react immediately to state updates via `subscribeState(fn)`.

3.2 Graduated Reticle & Click Distance Math (js/renderer/overlayManager.js)
  - Renders dynamic graduated reticle SVG based on `appState.reticleConfig`:
      * `clickCount`: indents per arm (2 to 25)
      * `clickSpacing`: pixel distance between clicks
      * `centerGap`: unobstructed central viewport area
      * `innerBrackets`: bounding POI crosshair brackets
      * `majorInterval`: longer tick lines every N clicks
      * `showLabels`: click distance number markings
      * `concentricRings`: circular distance rings
  - Exports `getClickDistanceInPixels(viewportW, viewportH, overlayScale)` to calculate
    the physical on-screen pixel distance represented by 1 click, factoring both SVG viewBox
    scaling and user overlay scale.

3.3 Female Voice Text-To-Speech Detection Announcements (js/renderer/compositor.js)
  - `announceHeatmapDetection(detections, cw, ch)`:
      * Finds the strongest cluster of localized motion from the heatmap grid.
      * Calculates clockwise angle from the reticle center (0.5, 0.5) in 12 clock hours.
      * Calculates Euclidean distance in clicks using `getClickDistanceInPixels()`.
      * Generates phrases such as: "Detection! 11 o'clock, 3 clicks".
  - `speakDetectionAnnouncement(text)`:
      * Dispatches `SpeechSynthesisUtterance` via local browser speech engine.
      * Auto-selects English female voices (e.g. Zira, Samantha, Victoria, Google UK English Female).
      * Applies robotic/crisp female pitch (default 1.25x) and speed (1.10x).
      * Debounces repeat alerts to prevent audio chatter.

3.4 PS4 / Bluetooth Gamepad Controller (js/input/gamepadController.js)
  - Polled every animation frame using HTML5 `navigator.getGamepads()`.
  - Analog stick deadzone filtering (0.16) and non-linear acceleration for precision ROI crosshair steering.
  - Silently operates without modifying the screen unless buttons are triggered.
  - Live connection status dot, device name, and last action are displayed in Settings.

3.5 Native Dual-Direction Frame Stepping (instantReplay.js, videoBrowser.js)
  - Both Instant Replay and Saved Video Gallery provide:
      * `STEP -1`: Steps backward exactly 1 frame (`playheadSec - frameStepSec`).
      * `STEP +1`: Steps forward exactly 1 frame (`playheadSec + frameStepSec`).
      * Pauses playback automatically and re-renders the exact decoded frame immediately.


4. PORTABLE USAGE GUIDE (USB STICK / LAPTOP / CHROMEBOOK)
---------------------------------------------------------
Option A: Running Directly from a USB Stick on Any Laptop (Windows / Mac / Linux)
  1. Copy the `/EagleVision` folder onto your USB drive.
  2. On Windows: Double-click `start_eaglevision.bat` inside the folder.
  3. On macOS / Linux terminal: Run `python3 -m http.server 8080` and open
     `http://localhost:8080` in Chrome, Edge, or Brave.

Option B: Installing as a 100% Offline App on Lenovo Duet 3 / Laptop
  1. Open `http://localhost:8080` in Chrome and click "Install EagleVision" in the address bar.
  2. Once installed, launch EagleVision from the app shelf anytime 100% offline.
