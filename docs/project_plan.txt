1. OVERVIEW & DESIGN PHILOSOPHY
-------------------------------
SPOTR is an installable, offline-capable Progressive Web App (PWA) paired
with a high-performance Python 3 RTSP streaming gateway. Built for tactical field
use on the Lenovo IdeaPad Duet 3 (10.95" 2000x1200 touch display, ChromeOS),
Android tablets, and Windows/Linux/macOS laptops, it connects to:
  - Wired UVC USB cameras (webcams, microscopes, inspection scopes, capture cards)
  - Network Wi-Fi / IP cameras (e.g., Bresser Full HD Wi-Fi Eyepiece Camera, ONVIF)

Core Capabilities:
  - 100% Full-Screen Camera Viewport with minimal UI footprint
  - Hardware-Promoted Graphics: Desynchronized Canvas 2D ({ alpha: false, desynchronized: true })
    with GPU layer promotion (contain: strict; translateZ(0)) and touch-action: none
  - Touch-first controls (52px hit targets, 16px-18px high-contrast typography)
  - 1-Tap Declutter Mode: Hide all interface chrome with one tap; single restore icon
  - Top-Left Unified Toolbar: Settings Screen Shortcut, PiP Zoom Loupe Toggle,
    Reticle Quick Drawer Toggle, Micro-Change Heatmap Toggle, Telemetry HUD Toggle,
    Studio Voice Mute/Unmute, and Whole-Image Zoom Stepper (- / 1.0x / + / 1:1)
  - Reticle Quick-Drawer:
      * Instant First Focal Plane (FFP) Lock toggle
      * Opacity (0% - 100%) and Reticle Scale (10% - 200%) sliders
      * 6 Tactical Color Themes (Emerald Teal, Amber Gold, High-Vis White, Night Blue, Ruby Red, Amethyst)
      * Center Aiming Point Selector (Empty, Dot, Cross, Chevron)
  - Dedicated Fullscreen Settings Screen (Screen 3):
      * Multi-column tactical grid for camera source (USB vs. RTSP Bresser/Custom),
        memory buffer parameters, reticle overlay configuration, heatmap & voice callouts,
        PS4/Bluetooth gamepad mapping, image filters, and Bluetooth ring calibration
  - Dedicated Fullscreen Reticle Customizer & Click Calibration (Screen 4):
      * Live interactive SVG graduated reticle with configurable clicks/indents per arm (2 to 30),
        click pixel spacing, unobstructed center gap, center brackets, major ticks,
        number labels, concentric distance rings, and stroke weight
      * Interactive audition stage: click anywhere on the reticle stage to simulate detection
        and audition female robotic voice announcements
  - High-Fidelity Studio Voice Synthesizer & Speech Engine:
      * Web Audio API player (voiceAudioEngine.js) playing pre-recorded studio clips
        from an audio sprite (voice-sprite.mp3, voiceManifest.js) with zero latency
      * Local Web Speech API fallback for environments without audio sprite support
      * Speaks angle (1 to 12 o'clock) and distance in graduated reticle clicks:
        e.g., "Detection! 11 o'clock, 3 clicks"
      * Dynamically adapts to custom reticle spacing, user overlay zoom scale, and FFP zoom
  - PS4 / DualSense / Bluetooth Gamepad Support (WebHID & HTML5 Gamepad API):
      * WebHID direct connection for Sony DualShock 4 / DualSense controllers
      * Capacitive Touchpad Virtual Mouse cursor with L2 (left click/drag) and R2 (right click)
      * Left Analog Stick: Smooth accelerated ROI crosshair aiming (0.16 deadzone + 1.8 power curve)
      * Right Analog Stick: Smooth camera pan when zoomed in (>1.0x)
      * L1 / R1: Zoom In / Out; L2 / R2: Step -1 / +1 Frame
      * L3 / R3: Theme cycle / Recenter
      * D-Pad: Tool cycling & FFP subtension adjustments
      * Options: Settings; Share: Instant Replay (Auto-Save)
  - Decoupled 20Hz Micro-Change Heatmap Engine:
      * Executes on an independent 50ms interval, decoupling computer vision from the 60fps compositor
      * High-contrast thermal markings; global motion gate (>18%) rejects camera shake & tripod bumps
      * Dirty checking state machine skips canvas rendering when scene is static
      * Configurable sensitivity (10% - 95%) and display duration (0.5s - 10.0s up to infinity)
  - Native-Resolution In-Memory Video Buffer (5s-60s @ 5-30 FPS) with live RAM meter
      * Dual-source ingestion: grabs full-res frames from <video> (USB) or getRtspCanvas() (RTSP)
  - One-Tap Instant Replay with Auto-Save to IndexedDB:
      * 0.5x Slow-Motion button for bullet trajectory and impact forensics
      * STEP -1 / STEP +1 dual-direction frame stepping
  - Fullscreen Stored Video Player (Screen 2):
      * Floating GUI overlay and collapsible Clips drawer
      * Individual red trash icon on each clip card for rapid deletion without opening player
      * Dual STEP -1 / STEP +1 frame buttons and native-res .webm export

3. HOW KEY SUBSYSTEMS WORK & CONNECT
------------------------------------

3.1 Central Reactive State (js/state.js)
  - Holds the single source of truth (`appState`) for all screens ('live' | 'gallery' | 'settings' | 'reticle' | 'controller'),
    camera source mode (`cameraSource`: 'usb' | 'rtsp'), RTSP configurations, zoom levels, ROI target `(roiX, roiY)`,
    overlay state, FFP lock mode (`reticleFfpMode`), reticle configuration (`reticleConfig`),
    heatmap sensitivity, duration, speech announcements, voice settings, and gamepad telemetry.
  - Subscribed modules react immediately to state updates via `subscribeState(fn)`.

3.2 RTSP Gateway & Condition Push Pipeline (server.py)
  - Employs an OpenCV (`cv2.VideoCapture`) worker thread continuously pulling network frames.
  - Distribution uses `threading.Condition(frame_lock)` to immediately wake client HTTP stream threads
    the exact microsecond a new frame arrives, eliminating polling sleep cycles and reducing latency to <1ms.
  - Built-in UDP wake endpoint `/api/rtsp/wake` sends `b"bresser"` to `192.168.1.1:65534` to wake
    Bresser Full HD Wi-Fi Eyepiece Cameras. Supports `ch0` (1080p) and `ch1` (540p) RTSP channels.

3.3 Graduated Reticle & First Focal Plane Math (js/renderer/overlayManager.js)
  - Renders dynamic graduated reticle SVG based on `appState.reticleConfig`:
      * `clickCount`: indents per arm (2 to 30)
      * `clickSpacing`: pixel distance between clicks
      * `centerGap`: unobstructed central viewport area
      * `centerPointStyle`: 'empty', 'dot', 'cross', or 'chevron'
      * `innerBrackets`: bounding POI crosshair brackets
      * `majorInterval`: longer tick lines every N clicks
      * `showLabels`: click distance number markings
      * `concentricRings`: circular distance rings
  - Implements First Focal Plane (FFP) scaling:
      `scaleFactor = (overlayScale / 100) * (reticleFfpMode ? mainZoom : 1.0)`
  - Exports `getClickDistanceInPixels()` to calculate the physical on-screen pixel distance
    represented by 1 click, factoring both SVG viewBox scaling and user overlay scale.

3.4 Studio Voice Synthesizer & Speech Engine (js/audio/voiceAudioEngine.js)
  - Preloads studio recorded audio sprite (`voice-sprite.mp3`) using browser Web Audio API (`AudioContext`).
  - Plays concatenated audio samples for clock coordinates and reticle clicks without speech synthesis latency.
  - Automatically falls back to browser `SpeechSynthesisUtterance` if Web Audio assets fail.
  - Generates announcements such as: "Detection! 11 o'clock, 3 clicks".

3.5 Decoupled 20Hz Heatmap Engine (js/renderer/compositor.js)
  - Heatmap frame analysis runs on an independent 50ms interval, entirely decoupling heavy
    matrix difference calculations from the 60fps main canvas compositor.
  - Global Camera Shake Gate: Motion exceeding 18% of the frame is rejected to prevent false positives
    caused by wind, tripod vibrations, or panning.
  - Dirty checking state machine skips canvas draw commands when the scene is quiescent.

3.6 Native Dual-Source RAM Ring Buffer (js/recorder/memoryRingBuffer.js)
  - Automatically captures full-resolution frames from `<video id="cameraVideo">` in USB mode,
    or from the offscreen canvas helper `getRtspCanvas()` in RTSP mode.
  - Maintains 5s to 60s rolling JPEG frames in memory with real-time heap guardrails.

3.7 Instant Replay & Stored Video Player (instantReplay.js, videoBrowser.js)
  - Instant Replay modal features a dedicated `0.5x` Slow-Motion button for detailed ballistic analysis.
  - Fullscreen Stored Video Player provides a collapsible clips drawer with individual red trash icons
    (`.btn-quick-delete-clip`) on each card for rapid one-tap deletion without loading the full video.


4. PORTABLE USAGE GUIDE (USB STICK / LAPTOP / CHROMEBOOK)
---------------------------------------------------------
Option A: Running Locally on Windows
  1. Double-click `start_spotr.bat` in the root folder.
  2. The batch script automatically starts `python server.py 8080` (with RTSP gateway and UDP wake support)
     and launches `http://localhost:8080` in your default browser.

Option B: Running on macOS / Linux Terminal
  1. Open a terminal in the SPOTR directory.
  2. Run `python3 server.py 8080` (or `python3 -m http.server 8080` for UVC-only mode).
  3. Open `http://localhost:8080` in Chrome, Edge, or Brave.

Option C: Installing as a 100% Offline App on Chromebook / Android / Laptop
  1. Open `http://localhost:8080` in Chrome or Edge.
  2. Click the "Install SPOTR" icon in the omnibox (or "Add to Home Screen" on mobile).
  3. Launch SPOTR from your app launcher anytime with complete 100% offline functionality.
