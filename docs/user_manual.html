OPTICS Dual Camera Ingestion: UVC USB & Wi-Fi RTSP

SPOTR features a universal dual video ingestion pipeline supporting both wired USB scopes and wireless network cameras.

  • UVC USB Scopes & Webcams: Direct driverless HTML5 MediaDevices capture with automatic hot-plug renegotiation at 1080p/4K @ 60 FPS.
  • Bresser Full HD Wi-Fi Eyepiece Camera: Integrated gateway (server.py) automatically dispatches UDP wake magic packets (/api/rtsp/wake to port 65534) and supports dual Anyka DSP streams:
    • Channel 0 (1080p): Full HD optics at rtsp://192.168.1.1:554/live/ch0.
    • Channel 1 (540p): High-framerate stream at rtsp://192.168.1.1:554/live/ch1.
  • Custom RTSP & ONVIF IP Cameras: Connect any network IP camera via custom RTSP URL with sub-millisecond push-event frame distribution.
  • Synthetic Test Pattern: Fallback test card with calibrated hash lines to verify compositor and reticle calibration without hardware attached.
Condition-Push Frame Distribution

The Python OpenCV gateway coordinates worker threads via threading.Condition, delivering incoming frames immediately to browser clients with zero polling jitter.

  • 5-Button Bluetooth Remote Ring: Full hands-free remote control for finger rings with interactive key calibration in Settings.

DETECTION 20Hz Decoupled Micro-Change Heatmap Engine

SPOTR features an advanced micro-movement detection algorithm that highlights subtle changes (bullet impacts, target movement, wind drift) as a high-contrast thermal glow overlay.

  • 20Hz Decoupled Pipeline: Heatmap analysis executes on an independent 50ms timer, decoupling heavy frame diffing from the 60 FPS compositor to prevent UI hitching.
  • Downsampled Luma Analysis: Evaluates a high-speed 160×90 luminance matrix (14,400 cells) against an exponential moving average background.
  • Global Shift Rejection (>18%): Automatically discards whole-frame camera movements (wind buffeting, scope recoil, tripod bumps) to prevent false alerts.
  • Adjustable Sensitivity (10% to 95%): Fine-tune detection thresholds in Settings to spot minute paper tears at 1000 yards without triggering on heat mirage.
  • Decay Duration (0.5s to 10s): Controls how long the visual impact heat bloom persists before fading.
SPEECH Studio Voice Synthesizer & Web Speech Engine

When movement or bullet impact is detected, SPOTR computes the geometric centroid vector relative to your scope crosshair and vocalizes directional corrections.

  • High-Fidelity Studio Voice Sprite: Uses Web Audio API (voiceAudioEngine.js) with studio-recorded female voice clips (voice-sprite.mp3) for crystal-clear, zero-lag announcements.
  • Browser TTS Fallback: Activates native SpeechSynthesisUtterance if Web Audio is unsupported.
  • Clock & Reticle Click Announcements: Announces target clock angle ($1$ to $12$ o'clock) and distance in graduated reticle clicks: e.g. "Detection! 11 o'clock, 3 clicks".
  • Instant Voice Mute: Click the speaker icon in the top-left toolbar or press the Mute hotkey to instantly silence audio without disabling visual heatmap rendering.

IN-MEMORY Native-Resolution Circular RAM Ring Buffer

SPOTR maintains a 100% RAM-only rolling queue (memoryRingBuffer.js) with zero disk writes during surveillance, protecting flash memory from wear.

  • Dual Source Ingestion: Seamlessly ingests full-resolution frames from either UVC USB video or RTSP network streams (getRtspCanvas()).
  • Configurable Duration: Store from 5 to 60 seconds of rolling historical video in RAM.
  • Configurable Buffer FPS: Set buffer capture between 5 and 30 FPS to optimize RAM footprint on low-memory devices.
  • Live RAM Budget Meter: Real-time telemetric bar in Settings displays Current Used MB, Estimated Allocation, and Free Device RAM.
  • Automatic Memory Guardrails: Proactively purges older frames if device memory pressure exceeds threshold.

RETICLE Parametric Reticle Studio & First Focal Plane (FFP)

  • First Focal Plane (FFP) Lock: Dynamically scales hashmark spacing and reticle subtensions in lockstep with whole-image digital zoom, maintaining true angular mil/MOA values.
  • Extended 30-Click Elevation/Windage Ladder: Display up to 30 clicks per arm with major graduation labels (every 5 or 10 clicks) across vertical and horizontal axes.
  • Optical Dead-Center Measurement: All click distances and voice callout turret adjustments are calculated strictly from true optical dead-center (0, 0), completely independent of visual center gap diameter.
  • 4 Selectable Center Aiming Symbols:
    • EMPTY: Open unobstructed center viewing window.
    • DOT: Precision center aiming dot at the optical origin.
    • CROSS: Fine mini-crosshair intersection at dead-center.
    • CHEVRON: Tactical inverted caret (Λ) whose sharp apex points directly to the center pixel.
  • Direct Controller Sculpting & Cycle: Adjust click count, spacing, gap, stroke weight, or press Key C / Quick Tool dock to cycle center point styles live.
CALIBRATION MOA & MRAD Turret Click Calculator

Eliminate sighting guesswork by calculating exact optical turret click offsets directly from observed bullet impacts:

  • Target Distance Input: Enter engagement distance in Yards or Meters.
  • Turret Value Selection: Select your scope turret click standard (1/4 MOA, 1/8 MOA, 1/2 MOA, 0.1 MRAD, or 0.05 MRAD).
