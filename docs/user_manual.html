4. HARDWARE CONTROLLERS, BT RING ISOLATION & SHORTCUTS
PAGE 5 OF 5
WEBHID DualShock 4 / DualSense
Touchpad drives Virtual Mouse; L2 left-clicks/drags; R2 right-clicks; L1/R1 zoom; Share opens Replay. Polls only while connected (0% idle CPU).
K-MODE 8BitDo Micro
Set bottom switch to K (HID keyboard) for zero-sleep 16-button control. Select 8BitDo Micro in Setup → Controllers for native screen-scoped mappings.
ISOLATED Bluetooth Ring
OFF (Isolated) by default so it never hijacks 8BitDo Micro or keyboards. Enable BT Ring: ON in Setup → Controllers → Bluetooth Ring when pairing a Ring.
