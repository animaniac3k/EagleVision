1. Inputs, Ingestion & State
ISOLATED HARDWARE INPUTS gamepad + ring
  • DualShock 4 / DualSense (WebHID): Demand-driven polling (0% CPU when idle), touchpad virtual mouse, L2/R2 drag/click, dt-normalized sticks.
  • 8BitDo Micro (K-Mode): 16-button zero-sleep HID keyboard profile with screen-scoped shortcuts.
  • Bluetooth Ring (Isolated): Disabled by default (ringEnabled: false) so it never hijacks 8BitDo Micro or keyboard navigation.
  • Keyboard & Touch: Screen-scoped shortcuts (I HUD, N Snapshot, R Replay) & pinch-zoom / pan gestures.
MULTI-SOURCE CAMERA ENGINE streamManager
  • UVC USB Cameras: Browser getUserMedia + native Android libuvc (UsbUvcSessionManager.kt).
  • Bresser Wi-Fi (192.168.0.1): Validated local wake proxy (/api/rtsp/wake) + ch0 (1080p) / ch1 (540p) with Android 10+ camera Wi-Fi binding.
  • Resilient Recovery: 4-step exponential backoff auto-reconnect + truthful RTSP status & FPS telemetry.
  • Gateway Pause Sync: Automatically pauses JPEG/H.264 decode off Live & Calibration.

2. Compositor, CV & Voice
DUAL-CANVAS COMPOSITOR compositor.js
A. Frame-Deduped 60 FPS Video + Overlay
• Skips redundant USB <video> blits via currentTime.
• Stops rAF completely off Live/Calibration or when tab hidden.
• Zero-flicker #liveOverlayCanvas for Hit Pins & adaptive timestamps.
• Annotated PNG snapshot bakes CSS filters, reticle, pins & timestamps.
B. 20Hz Consolidated Micro-Change Detector
• 160×90 luminance grid with Float64Array tracking & Ignore Masks.
• Global Shake Gate (>18%) + Max Hit Area (default 5%) + Min Cells.
• 1-tap ✦ Auto-Tune samples live scene noise floor for 1.3s.
• 14,400-cell thermal debug putImageData runs only on Calibration.
C. Lazy Studio Voice Engine (voiceAudioEngine.js)
• Decodes voice-sprite.mp3 lazily (saves 19–38 MB RAM when muted).
• Cycles OFF → POI → POA with Cartesian + clock-face callouts (e.g. "2 left, 3 up" / "11 o'clock, 3 clicks").
• Generation cancel tokens prevent overlapping speech queues.
PARAMETRIC RETICLE & LOUPE overlay + zoom
  • First Focal Plane (FFP): Scales crosshair subtensions 1:1 with digital zoom.
  • Unified Theme Swatches: 6 tactical swatches + custom picker with WCAG-computed button text contrast.
  • Persisted Custom Reticle: Uploads stored as DataURL (<= 1 MB) across restarts.
  • Digital Loupe (PiP): 1.5x–12.0x movable/resizable zoom window with Loupe AA auto-snap to hits.
3. RAM Buffer, Archive & Native Hosts
LIVE-ONLY RAM RING BUFFER memoryRingBuffer
  • Zero Disk Wear: Circular in-memory JPEG queue (5–60s @ 5–30 FPS), active strictly on Live screen.
  • Tablet RAM Guardrails: Adapts memory cap via navigator.deviceMemory (<= 220 MB on 4 GB Duet 3).
  • Generation-Safe Reset: Prevents async toBlob races when switching cameras or clearing buffers.
UNIFIED PLAYBACK & HITS MAP Screen 2
  • Playback Tab: Opens LIVE BUFFER (RAM) unsaved; 0.5x slow-mo, -1/+1 frame step, audio-peak CCTV scrubber, on-demand Save Clip & .webm export (picker invoked before encoding).
  • Memory Cleanup: Frees 50–300 MB activeBufferClip immediately upon returning to Live.
  • Spatial Hits Map: Synced Reticle: ON/OFF & Hits: ON/OFF, 1-tap Re-Zero & Clear, in-place age timers, PNG snapshot export.
NATIVE ANDROID & WINDOWS HOSTS Kotlin + Python
  • Android APK (v0.62.1 / vCode 63): SpotrServer.kt chunked asset streaming, RFC 2617 Digest auth, RFC 2435 MJPEG-over-RTP, fast semi-planar NV21 copy, HW→SW decoder fallback, FLAG_KEEP_SCREEN_ON & low-latency WifiLock.
  • Windows/Desktop (server.py): TCP_NODELAY + coalesced MJPEG writes, localhost-by-default security (--lan opt-in for iOS/iPad), SSRF & scheme validation.
OFFLINE PWA ENGINE (core/sw.js • spotr-v0.62.1) Pre-caches all 40 core assets for 100% offline field use. Bypasses cross-origin camera requests (192.168.0.1) so camera wake probes never hang, and preserves active hits across SW updates.
LOW-POWER ENGINE & INPUT ISOLATION Demand-driven compositor/gamepad/playback loops, GPU scaleX() meters, lazy voice decoding, RAM caps, and opt-in Bluetooth Ring isolation keep 4 GB tablets cool and responsive on the range.
